# TOCO Speciality

Crafted Coffee. Refined Taste. — Addis Ababa.

Site vitrine de TOCO Speciality (Kazanchis, face à l'Addis Aquarium) : café de spécialité, pâtisserie fine et cuisine, sous un plafond qui ondule comme une vague.

## Lancer en local

```bash
python3 serve.py
```

Puis ouvrir <http://localhost:4173>.

## Structure

- `index.html` — le site (une seule page : HTML + CSS + JS vanilla, GSAP/ScrollTrigger/Lenis via CDN)
- `404.html` — page d'erreur
- `assets/` — photos, logos (wordmark + monogramme), vidéo, avis

Site réalisé par Studio HDM.
